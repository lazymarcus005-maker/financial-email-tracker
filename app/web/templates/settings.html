{# Setup: stdio #}

Setup — stdio

ใช้กับ local agent เช่น Claude Desktop, Cursor, Windsurf ที่รันบนเครื่องเดียวกับ server

Environment variables ที่ต้องตั้ง

MCP_OWNER_USER_ID=1
DATABASE_PATH=data/finance.db
# หรือ DATABASE_BACKEND=postgres + DATABASE_URL=...

Claude Desktop / Cursor — mcp.json หรือ claude_desktop_config.json

{
  "mcpServers": {
    "financial-email-tracker": {
      "command": "python",
      "args": ["-m", "app.mcp.server"],
      "env": {
        "MCP_OWNER_USER_ID": "{{ settings.mcp_owner_user_id or '1' }}",
        "MCP_TRANSPORT": "stdio",
        "DATABASE_PATH": "{{ settings.database_path }}"
      }
    }
  }
}
{# Setup: SSE #}

Setup — SSE (HTTP)

ใช้กับ remote agent หรือ agent ที่ต่อผ่าน HTTP — ต้องตั้ง MCP_API_TOKEN

รันด้วย environment variables

MCP_TRANSPORT=sse \
MCP_HOST=0.0.0.0 \
MCP_PORT={{ settings.mcp_port }} \
MCP_API_TOKEN=your-secret-token \
MCP_OWNER_USER_ID={{ settings.mcp_owner_user_id or '1' }} \
python -m app.mcp.server

Endpoint & Auth header

Endpoint : http://<host>:{{ settings.mcp_port }}/sse
Header   : Authorization: Bearer <your-secret-token>
{# Setup: streamable-http #}

Setup — Streamable HTTP

HTTP transport แบบ MCP spec 2025-03-26 รองรับ stateless mode

MCP_TRANSPORT=streamable-http \
MCP_HOST=0.0.0.0 \
MCP_PORT={{ settings.mcp_port }} \
MCP_API_TOKEN=your-secret-token \
MCP_OWNER_USER_ID={{ settings.mcp_owner_user_id or '1' }} \
python -m app.mcp.server
Endpoint : http://<host>:{{ settings.mcp_port }}/mcp
Header   : Authorization: Bearer <your-secret-token>
{# docker-compose snippet #}

docker-compose — เพิ่ม MCP service

เพิ่ม service แยกใน docker-compose.yml เพื่อรัน MCP server ควบคู่กับ web app

  mcp:
    build: .
    command: python -m app.mcp.server
    ports:
      - "{{ settings.mcp_port }}:{{ settings.mcp_port }}"
    volumes:
      - /opt/finance/data:/app/data
      - /opt/finance/secrets:/app/secrets
    environment:
      - DATABASE_BACKEND=${DATABASE_BACKEND:-aiosqlite}
      - DATABASE_PATH=${DATABASE_PATH:-/app/data/finance.db}
      - MCP_TRANSPORT=sse
      - MCP_HOST=0.0.0.0
      - MCP_PORT={{ settings.mcp_port }}
      - MCP_API_TOKEN=${MCP_API_TOKEN}
      - MCP_OWNER_USER_ID=${MCP_OWNER_USER_ID:-1}
    restart: unless-stopped
    networks:
      - finance
